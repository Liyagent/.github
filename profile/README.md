<br>

Liyagent runs AI agents inside the business systems a company already uses: IT service desks, HR, SAP, Salesforce, Dynamics 365 and finance.

Every agent acts as the person who asked, with that person's permissions. Any action that changes data waits for a person to approve it. Each agent has a spending limit. Every action is recorded in a signed audit log that anyone can verify.

Liyagent runs on your own infrastructure with the AI model of your choice.
