Liyagent runs AI agents inside the systems a company already uses — IT service desks, HR, SAP, Salesforce, Dynamics 365 and finance — and keeps them accountable. Every agent acts as the person who asked, with that person's permissions. Writes wait for a person's approval. Spend is capped per agent. Every action lands in a hash-chained audit log whose exports are signed, so anyone can verify them without trusting the server that produced them.

It runs on your own infrastructure — a VM, Docker Compose or Kubernetes — with the model you choose, including open models on your own hardware.
